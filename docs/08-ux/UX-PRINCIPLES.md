# UX principles

Related: [INFORMATION-ARCHITECTURE.md](INFORMATION-ARCHITECTURE.md) · [ACCESSIBILITY.md](ACCESSIBILITY.md)

1. **Role-aware, not feature-dump.** Employees never see CAB queues.
2. **Operational density for IT; calm simplicity for employees.**
3. **Honesty.** Do not show a single compliance % without methodology.
4. **Continuity.** Ticket page shows CI, sessions, related incident/problem/change.
5. **Safety.** Destructive/privileged actions confirm; unattended is visually distinct (warning).
6. **UTC stored; local displayed** with timezone indicator in headers.
7. **Empty and error states** are designed, not blank tables.
8. **i18n keys** from the start.
