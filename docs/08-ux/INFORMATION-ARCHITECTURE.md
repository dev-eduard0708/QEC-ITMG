# Information architecture

Three experiences, separate layouts.

## 1. Employee

My Tickets, Create Request, My Equipment, Knowledge Base, Remote consent inbox, My profile/notifications. No admin, no CMDB graph, no controls.

## 2. IT personnel

Dashboards (ops), queues, tickets, incidents, problems (when live), changes, assets/CMDB, remote sessions, events/monitoring (when live), knowledge, operational reports. Modules appear only with permissions.

## 3. Governance / management / audit

Controls, policies, risks, compliance, evidence, audit, findings, executive/governance reports. IT managers may have both IT + a subset of reports.

Cross-links always go to authorized records; 404 if not permitted.
