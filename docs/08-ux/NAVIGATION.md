# Navigation

Primary nav is **permission-filtered**. Group labels:

**Employee:** Home, Requests, Equipment, Knowledge, Remote, Notifications

**IT:** Dashboard, Service Desk, Remote, Changes, Assets, Operations, Knowledge

**Governance:** Governance, Policies, Compliance, Evidence, Audit, Risks, Reports

**Admin:** Administration (users, roles, lookups, workflows, integrations, settings)

A user with multiple hats sees a **workspace switcher** (Employee | IT | Governance) rather than one infinite sidebar. Default workspace from roles.

Remote Support children: Request, Consent (employee), Active, History, Audit log — each permission-gated.
