# Audit readiness

Related: [../03-modules/AUDIT-MANAGEMENT.md](../03-modules/AUDIT-MANAGEMENT.md) · [EVIDENCE-STRATEGY.md](EVIDENCE-STRATEGY.md)

## Readiness view (server-side)

For a period and framework version:

- Unmapped requirements
- Controls without current Accepted evidence
- Expired evidence
- Open findings / overdue CAPA
- Policies overdue review
- Exceptions expiring
- DR tests missing for critical services (when BCM live)

## Export pack

Manifest + files + hashes. Actor, purpose, scope. Classification-aware.

## People

Auditor role is read-oriented. Management responses are write on findings without granting `admin.roles`.
