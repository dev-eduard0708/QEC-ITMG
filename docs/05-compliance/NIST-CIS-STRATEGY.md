# NIST CSF and CIS Controls strategy

## NIST CSF

A **risk-based cybersecurity outcomes** framework (functions: Identify, Protect, Detect, Respond, Recover — versions evolve). Useful for cybersecurity program structure. Not a management system standard like ISO 27001. Not COBIT.

Load as framework version (CSF 2.0 categories/subcategories as requirements). Map internal controls. Use for security dashboard alignment.

## CIS Controls

A **prioritized technical/safeguard catalog**. More prescriptive than NIST CSF functions. Not equivalent to COBIT governance or ISO ISMS clauses.

Load CIS version (v8.x safeguards) as requirements. Map to technical internal controls (inventory, hardening, backups). Implementation groups (IG1/IG2/IG3) can be tags on requirements.

## Together with ISO/COBIT

Same InternalControl (e.g. privileged review) may map to CIS safeguard, NIST subcategory, ISO Annex A, and a COBIT practice. Assessments still happen once per control per period.
