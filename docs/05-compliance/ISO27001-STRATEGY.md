# ISO/IEC 27001 strategy

## Purpose

ISO/IEC 27001 is an **ISMS** standard: scope, leadership, risk, Annex A (or equivalent) controls, statement of applicability, continual improvement. Certification is an organizational audit outcome.

## In QEC ITMG

- Framework version e.g. 2022 Annex A / clauses as requirements
- Internal controls map to Annex A themes (IAM, crypto, ops, …)
- ISMS documents live in Policy/Document management
- SOA is a **report**: mappings + exclusions with exceptions
- Evidence library supports certification audits but does not replace the auditor

## Honesty

Green mapped coverage ≠ issued certificate. The platform tracks work and SoA data.
